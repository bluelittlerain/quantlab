# Fixed Hong Kong SMA Example

This example is generated by the bundled, completely offline HK smoke provider. It exercises the
same symbol, board-lot, signal, cash-ledger, benchmark, serialization, and export boundaries as the
desktop application without downloading market data.

It is intentionally small enough to verify by hand and **does not claim to represent historical
0700.HK or 2800.HK performance**.

## Configuration

- Symbol: `0700.HK`
- Tradable benchmark: `2800.HK`
- Analysis dates: `2024-01-02` to `2024-01-05`
- SMA: `1 / 2`
- Initial capital: `HK$10,000`
- Board lot: `100`
- Costs and slippage: zero, so timing and lot accounting remain easy to audit
- Fixture generation time: `2024-01-06T00:00:00Z`

Regenerate only from the fixed provider:

```powershell
$env:QUANTLAB_OFFLINE = "1"
.venv\Scripts\python scripts\generate_hk_formal_example.py
```

The generator refuses to write outputs if the fixed `run_id` or market-data fingerprint changes.

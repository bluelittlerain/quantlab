# 局域网访问

QuantLab 桌面版默认只监听 `127.0.0.1`。局域网访问必须由用户在“设置”中明确开启，并在下次启动时生效；关闭开关并重启后恢复为仅本机访问。

## 使用流程

1. 在桌面端打开“设置”，开启“允许局域网设备访问”。
2. 重启 QuantLab。
3. 桌面端设置页会显示局域网 URL、二维码和本次启动的六位配对码。
4. 手机连接同一可信私人网络，扫描二维码或输入 URL。
5. 首次访问输入配对码。成功后浏览器获得仅限本次后端进程的 HttpOnly 会话 Cookie。

配对码和令牌使用安全随机数生成。令牌不写入 SQLite、日志、URL、导出文件或 Git；QuantLab 关闭后全部失效。本机 loopback 会话受信任，但局域网客户端必须配对。

## 安全边界

- LAN 模式只用于可信家庭或办公内网，不会开放公网端口，也不会配置路由器端口转发。
- Windows 防火墙询问时只允许“专用网络”，不建议允许“公用网络”。QuantLab 不自动修改防火墙，也不要求管理员权限。
- API 不返回数据库、日志、缓存、浏览器配置或其他本机绝对路径。
- 二维码只包含局域网 URL，不包含配对码、令牌或用户数据。
- HTTP 局域网流量没有 TLS。不要在不可信 Wi-Fi 上启用；公网部署必须由 HTTPS 反向代理终止 TLS。

如果找不到有效的私有 IPv4 地址，启动器会安全回退为仅本机模式。多网卡机器目前选择排序后的第一个私有 IPv4；如该地址不可从手机访问，请关闭 LAN 模式并检查实际网络接口。

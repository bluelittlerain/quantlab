# QuantLab v0.2 港股产品规范

## 定位

QuantLab 是本地运行的港股日线研究与回测工具。它用于验证 SMA 双均线策略是否在透明成本口径下优于可交易基准，不接真实交易 API、不自动下单，也不承诺盈利。

## v0.2 垂直链路

1. 用户输入 `700`、`0700` 或 `0700.HK`，系统只规范化为 `0700.HK`，不猜测其他市场。
2. 用户选择分析日期、SMA 短长窗口、初始资金、每手股数和成本。
3. 数据层获取一致调整口径的 OHLC，验证日期、预热、交易日、OHLC 与指纹。
4. T 日收盘生成目标，T+1 开盘按整手成交；资金不足一手时保持现金并提示。
5. 策略与 `2800.HK` 使用同一初始资金、日期和执行原则，分别使用明确的每手股数与费用配置。
6. 后端生成指标、图表序列、交易账本、成本分解、数据元数据和导出文件。
7. 本地 SQLite 保存运行摘要、完整结果、预设、最近标的与设置。

## 首页回答的问题

- 测试了哪个港股、哪个日期区间和哪组 SMA 参数？
- 最终权益、CAGR 和最大回撤如何？
- 相比可交易基准的结果如何？
- 发生了多少交易，承担了多少总成本？
- 何时出现主要回撤，成本由哪些项目构成？

工程元数据（run_id、数据 SHA256、provider 版本、预热行数）只放在“数据与复现”。

## 明确不做

v0.2 不增加第二个策略、自动选股、参数优化、组合、分钟线、杠杆、做空、AI 预测或交易账户连接。

## 性能与生命周期

- 缓存回测目标小于 2 秒；本地历史摘要打开目标小于 500 ms。
- 长期服务必须有 readiness timeout、PID 所有权、有限清理和端口释放检查。
- React 不计算任何财务指标或交易配对；API 响应是唯一事实来源。

QuantLab v{{VERSION}} for Windows
============================

使用方法
--------
1. 双击 QuantLab.exe。
2. 等待 Microsoft Edge 或 Google Chrome 以独立应用窗口打开 QuantLab。
3. 在左侧研究参数区设置港股代码、日期、整手股数和成本，然后点击“运行回测”。
4. 如果未找到可用的隔离浏览器，程序会回退到系统默认浏览器并显示插件风险提示。
5. 关闭 QuantLab 隔离浏览器应用窗口后，本地服务会自动停止并释放端口。

运行边界
--------
- 应用默认仅监听 localhost，不接入真实下单，也不保存 API key。
- 日志、SQLite 历史和行情缓存统一存放在 %LOCALAPPDATA%\QuantLab。
- Edge 和 Chrome 分别使用 %LOCALAPPDATA%\QuantLab\browser-profile-v1 下的专属配置目录。
- 隔离窗口不读取日常浏览器配置或扩展，也不会修改默认浏览器设置。
- “允许局域网设备访问”默认关闭。只有用户在设置中明确开启并重启 QuantLab 后，
  FastAPI 才会监听局域网；每次启动使用新的六位配对码和仅存于内存的会话令牌。
- 程序不显示额外的桌面控制面板；页面左侧研究参数区是唯一的回测控制界面。
- 网页下载仍遵循浏览器的正常下载行为，不会写入 QuantLab 项目或 Release 目录。
- 历史回测只用于研究和工程验证，不构成投资建议。

窗口与服务生命周期
------------------
- QuantLab 独立浏览器应用窗口是桌面主入口，并会显示在 Windows 任务栏中。
- 最小化或被其他窗口遮挡后，可从 Windows 任务栏恢复；左侧参数栏可在页面内反复收起和展开。
- 关闭 QuantLab 独立应用窗口后，启动器只清理本次创建的浏览器进程树，然后停止
  FastAPI 服务并释放本地端口。
- 页面刷新、查看图表、展开交易记录和下载文件都不会启动第二个服务或浏览器窗口。
- 当前不引入 pystray。系统托盘会增加图像依赖、线程和打包生命周期复杂度，而现有独立
  应用窗口与任务栏入口已经覆盖正常恢复场景；如未来需要“关闭页面后继续后台运行”，
  再将托盘作为独立功能评估。

安全提示
--------
启用局域网访问时，Windows 防火墙可能询问是否允许 QuantLab 通信。只允许
“专用网络”，不建议允许“公用网络”。QuantLab 不会自动修改防火墙规则，也不要求
管理员权限。请只在可信家庭或办公网络中使用局域网模式。

本构建没有数字签名，Windows SmartScreen 可能显示“未知发布者”。运行前请用
Release 附带的 SHA256SUMS.txt 校验 ZIP 完整性。
